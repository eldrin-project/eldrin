  <project_name>Eldrin Platform</project_name>

  <overview>
    Eldrin is a comprehensive multi-project application marketplace and micro-frontend platform designed for Cloudflare deployment. The platform consists of several interconnected components: an application marketplace (eldrin-website) that provides a catalog of 43+ business applications for installation and deployment on Cloudflare infrastructure; a shell application (eldrin-core) that serves as the host for loading and managing installed applications with user management and authentication; framework-agnostic core libraries (eldrin-app-core) providing database migrations, authentication, event communication, and CLI tools for building and submitting applications; framework-specific adapters (eldrin-app-react, eldrin-app-angular, eldrin-app-vue, eldrin-app-svelte) for developing applications on different frontend frameworks using single-spa micro-frontend architecture; and template generators (create-eldrin-project) for scaffolding new Eldrin applications. The platform supports multiple database backends (Cloudflare D1, SQLite, PostgreSQL), provides inter-app communication through an event system, includes comprehensive permission-based access control, and features a sophisticated theming/white-labeling architecture for enterprise customization.
  </overview>
